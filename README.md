
# Projeto Arvore Binária com SuperVilões

Este projeto implementa uma estrutura de árvore binária de busca para gerenciar um ranking de supervilões, de acordo com o nível de maldade de cada um. Inclui funcionalidades de inserção, remoção, busca e ordenação dos vilões utlizando Java com POO.

# Funcionalidades
**Adicionar vilão (adicionaVilao)**
Insere um novo vilão na árvore de acordo com seu nível de maldade.

**Remover vilão (removeVilao)**
Remove um vilão da árvore com base no seu nome, tratando todos os casos possíveis:

Nó folha

Nó com um filho

Nó com dois filhos

**Buscar vilão mais malvado (buscaMaiorNivelDeMaldade)**
Percorre a árvore para encontrar o vilão com o maior nível de maldade.

**Ordenar vilões (ordenaViloes)**
Implementa o algoritmo QuickSort para ordenar um vetor de vilões com base no nível de maldade.

# Conceitos Envolvidos
Árvore binária de busca (BST)

Recursividade

Algoritmos de ordenação (QuickSort)

Estrutura de dados personalizada

Manipulação de nós em árvores
